# Portfólio — Joaquim Angelo

## Como visualizar
Abra o arquivo `index.html` no navegador.

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos e pastas deste projeto (mantendo `assets/`).
3. Em Settings → Pages, escolha a branch principal e a pasta `/root`.
4. Salve e aguarde a publicação.

## Personalização
- Foto: substitua `assets/joaquim-angelo.jpeg`.
- Conteúdo e links: edite `index.html`.
- Cores e layout: edite `style.css`.
- Menu e ano automático: `script.js`.

Os links dos três projetos e do GitHub já estão configurados.
